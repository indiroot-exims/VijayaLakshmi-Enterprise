## 🎯 Deduplication Rules Applied

1. **Same Name + Specs = Merge**
   - Example: "Ball Valve 1/4 inch" from KP Sales + Panam = 1 entry

2. **Similar Products, Different Names = Consolidate**
   - Example: "Male Connector", "Male Stud", "Straight Connector" = 1 entry

3. **Different Sizes = Same Product (Variant)**
   - Example: SS 304 90° Elbows 15-250 NB = 1 product entry with size range

4. **Different Materials = Separate Products**
   - Example: SS 304 vs SS 316 elbows = Separate entries

5. **Different Functions = Separate Products**
   - Example: 2-way vs 3-way solenoid valves = 2 entries
