TROUBLESHOOTING
================================================================================

Problem: Images not showing
Solution: 
  • Check ve-logo.jpg is in same folder as HTML files
  • Verify file names match exactly (case-sensitive on Linux)
  • Check browser console for errors (F12)

Problem: Styling looks broken
Solution:
  • Verify assets/css/style.css path is correct
  • Check that style.css is in assets/css/ folder
  • Clear browser cache (Ctrl+Shift+Delete)
  • Try different browser

Problem: Products not appearing
Solution:
  • Check assets/js/products.js loads without errors
  • Verify products.json or products array exists
  • Check browser console (F12) for JavaScript errors
  • Refresh page

Problem: Contact form not working
Solution:
  • Check assets/js/contact.js loads correctly
  • Verify form fields have correct IDs
  • Check browser console for errors
  • Try submitting again

Problem: Pages not linking
Solution:
  • Ensure all HTML files in same directory
  • Check file names (case-sensitive on Linux)
  • Verify href attributes point to correct files
  • Test links in different browser

Problem: Mobile menu not opening
Solution:
  • Check JavaScript is enabled in browser
  • Verify assets/js/script.js loads
  • Check console for errors
  • Try different browser
