## 🐛 Troubleshooting

### Products Not Showing?
- Check `assets/js/products.js` file exists
- Ensure file paths are correct
- Try refreshing the page (Ctrl+R)

### Form Not Submitting?
- Fill all required fields (marked with *)
- Check email format is correct
- Try a different browser
- Check browser console for errors (F12)

### Images Not Displaying?
- Ensure `ve-logo.jpg` is in public folder
- Check file paths in HTML
- Try re-uploading the image

### Mobile Menu Not Working?
- Click the hamburger (≡) icon
- Check JavaScript is enabled
- Try refreshing the page

## 💡 Tips & Tricks

### Search Tips
- Type partial product name (e.g., "304" for SS 304 fittings)
- Search by material (e.g., "brass", "stainless")
- Search by application (e.g., "pressure", "pneumatic")

### Filter Tips
- Use category filter for quick browsing
- Combine search + filter for precise results
- "All Categories" shows all 40 products

### Contact Form Tips
- Form pre-fills when clicking "Inquire" from products
- Data is saved locally in your browser
- Add more details in the message field for better response

### Mobile Tips
- Use hamburger menu (≡) on small screens
- Tap buttons to expand menus
- Scroll horizontally for product details if needed
